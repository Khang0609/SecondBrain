# Random Variables (Dr. Lê Xuân Đại, HCMUT-OISP)

Electronic lecture slides for **Random Variables** by **Dr. Lê Xuân Đại** (Department of Applied Mathematics, Faculty of Applied Science, Ho Chi Minh City University of Technology, 2025), 100 pages.

## Coverage
1. **Random Variables** — Mapping sample-space outcomes to real numbers.
2. **Discrete Random Variables** — Probability Mass Function (PMF) and Cumulative Distribution Function (CDF).
3. **Continuous Random Variables** — Probability Density Function (PDF) and CDF via integration.
4. **Characteristics of Random Variables** — Expected value (mean), variance, and standard deviation.
