# Claude Code

**Claude Code** (including the Code tab inside the Claude desktop application) is Anthropic's agentic coding environment capable of organizing project folders, writing and executing scripts, inspecting generated files/images, and packaging reusable Agent Skills.

## Role in SecondBrain Knowledge
- In [[claude-2d-character-animation-workflow]], Claude Code was used by a non-coder/non-artist to:
  1. Write pixel- and proportion-measuring scripts over 12 reference images (29 characters).
  2. Build a modular Python-to-[[svg|SVG]]-to-PNG character generator and 24/30 fps animation engine.
  3. Inspect rendered frames for visual bugs (such as hand/star occlusion) and package the entire pipeline into a reusable Skill (see [[skill-driven-agent-workflows]]).
